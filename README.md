# BeBaduy website — GitHub Pages starter

This folder contains a static website with:
- `index.html` — marketing / about page
- `privacy-policy.html` — privacy policy draft
- `support.html` — support page
- `style.css` — shared styling

## Before publishing
1. Replace `[YOUR SUPPORT EMAIL]` in `privacy-policy.html`.
2. Replace `[ADD-SUPPORT-EMAIL]` and the offline/internet answer in `support.html`.
3. Ask the developer to verify motion sensor processing, storage, analytics, crash reporting, and all included SDKs.
4. Update the privacy policy so it accurately reflects the final app build. Remove internal publication notes.
5. Confirm the copyright owner and year.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `bebaduy-website`.
2. Upload all files in this folder to the repository root (not inside an extra nested folder).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. The default URL will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/bebaduy-website/`

## App Store Connect URLs
If the repository is named `bebaduy-website`, the URLs will be:
- Marketing URL: `https://YOUR-GITHUB-USERNAME.github.io/bebaduy-website/`
- Privacy Policy URL: `https://YOUR-GITHUB-USERNAME.github.io/bebaduy-website/privacy-policy.html`
- Support URL: `https://YOUR-GITHUB-USERNAME.github.io/bebaduy-website/support.html`

Replace `YOUR-GITHUB-USERNAME` with the actual GitHub username after publishing. Do not submit placeholder URLs.
